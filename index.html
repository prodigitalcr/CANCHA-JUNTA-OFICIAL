Tutorial para activar CallMeBot

  1. Guarda el número +34 644 51 95 23 en tus contactos de WhatsApp.
  2. Envíale el mensaje exacto: I allow callmebot to send me messages
  3. Recibirás por WhatsApp tu APIKEY (cópiala).
  4. Ingresa tu número y APIKEY abajo y presiona Guardar.
Si cambias de número de WhatsApp, deberás volver a enviar el mensaje a CallMeBot para obtener una nueva APIKEY y actualizarla aquí.

Formato: código de país + número. Ej: 50612345678
